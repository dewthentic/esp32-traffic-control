# ESP32 Traffic Control

## Overview

ESP32 Traffic Control is a passion project to implement modern intersection and safety features into a micro-controller using embedded C++. The project is intended to strengthen my skills in the following topics:
- embedded C++/C++
- finite state machines (deterministic finite automatons)
- introductory circuit theory
- embedded systems/cyber-physical systems
- memory management
- internet of things (IoT)

Below, you may find documentation on the project and how the project works on the ESP32, as well as instructions to replicate it yourself. This project may potentially work on an Arduino or related product, but I cannot guarantee compatibility. This project is provided AS-iS, WITH NO WARRANTY OF ANY KIND.
